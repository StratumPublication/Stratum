Stratum editor

Edits StratumPublication/Stratum. Paste a GitHub token to publish straight to the live site, or work from a file on this computer.

Stored in this browser only. Never sent anywhere except GitHub.

Making the token. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Set Repository access to “Only select repositories” and pick Stratum. Under Permissions → Repository permissions, set Contents to Read and write. Give it an expiry you’re comfortable with.
